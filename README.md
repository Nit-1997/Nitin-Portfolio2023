# Nitin Bhat · Portfolio

Personal site at https://nitinbhat.info. Vite + React + Tailwind, prerendered to static HTML at build time.

```bash
npm install
npm run dev
npm run build
```

Content lives in `src/constants/index.js`. Update `public/sitemap.xml` `lastmod` and the JSON-LD `dateModified` in `index.html` when content changes.
